# KEX

KEX is a refactored food delivery app built by replacing Storyboard-based UI with programmatic layouts. Redesigned networking using Moya and improved architecture using RxSwift.

## Features
- Refactored legacy code
- Programmatic UI (SnapKit)
- RxSwift for reactive flow
- Firebase analytics

## Tech Stack
Swift, RxSwift, Moya, Firebase, SnapKit, UIKit
